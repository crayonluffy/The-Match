# The Match

A fun HTML5 canvas action game built with CreateJS.

## Play Now

**[Play The Match](https://the-match-7yk2.vercel.app/theMatch.html)**

## About

The Match is a browser-based action game where you control a matchstick character. Navigate through levels, avoid enemies, and use fire strategically to survive.

## Features

- 3 single-player levels with increasing difficulty
- HTML5 Canvas graphics with CreateJS
- Sound effects and background music
- Keyboard and mouse controls

## Controls

- **Arrow Keys** - Move character
- **Spacebar / Mouse Click** - Attack

## Tech Stack

- Node.js / Express
- HTML5 Canvas
- CreateJS (EaselJS, SoundJS, PreloadJS)
- EasyStar.js for pathfinding

## Local Development

```bash
cd myapp2
npm install
npm start
```

Then open http://localhost:3000
